# Kit Digital de Negociación Internacional — Tailandia

## Estructura

- `index.html` → portada
- `pages/mundo.html` → El país en el mundo
- `pages/ubicacion.html` → Ubicación, mapa y ciudades
- `pages/cultura.html` → Cultura de Tailandia
- `pages/equipo.html` → Integrantes del equipo
- `pages/negocios.html` → Protocolo y negocios internacionales
- `css/styles.css` → Diseño y colores
- `js/script.js` → Interacción del menú móvil
- `img/` → carpeta para imágenes locales futuras

## Cómo abrirlo

1. Descarga/descomprime la carpeta.
2. Abre `index.html` en Google Chrome.
3. No cambies de lugar las carpetas `css`, `js` y `pages`, porque las rutas ya están conectadas.

## Trabajo en equipo

Cada integrante puede modificar su página dentro de `pages/` y todos pueden compartir el proyecto mediante GitHub.

## Si aparece "Cannot GET"

Asegúrate de abrir la carpeta `TAILANDIA` completa en VS Code (no solamente `index.html`).

Con Live Server:
1. En VS Code selecciona `index.html`.
2. Clic derecho → **Open with Live Server**.
3. Navega desde el menú de la página.

También puedes abrir `index.html` directamente con Chrome; las páginas usan rutas relativas y deben permanecer dentro de la carpeta `pages`.
